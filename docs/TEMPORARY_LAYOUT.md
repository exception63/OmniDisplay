# 临时靠拢与完整恢复 · 0.4.9

用户可以在单次断开前预览剩余屏幕的新坐标。原主屏固定，旋转、显示模式和所有明确的左右/上下顺序保持；同一相连组件只做刚性平移。最终屏幕矩形不重叠，通过有长度的共同边连接，角点接触不算可达。

移除屏幕后，以含原主屏的组件为锚，其余组件选择最小轴向平移与已放置组件接边。单次平移不超过移除屏幕的宽/高，正交偏移保持；相同代价按稳定身份排序决定。当前算法保守支持横向、纵向及可轴向靠拢的折线排列。需要斜向移动、反转顺序或无法找到约束内结果的复杂拓扑会在断开前拒绝，不声称支持所有几何形状。

例如一块宽1080点的竖屏位于主屏和右侧横屏之间，移除后横屏可从x3000移至x1920，主屏和左侧竖屏保持不变。这是明确的产品策略；两次旧版现场观察不足以证明macOS必然禁止布局空隙。

## 独立快照

`layout-session.json` 保存完整原快照、目标身份和可重新计算的临时计划。请求摘要绑定两份排列，helper在写入前重新计算核验，不能用实际重排后的读数替换基准。离线期间不允许“以当前排列为准”覆盖原快照，也不允许继续断开另一块屏；先恢复完整排列。记录损坏或跨开机恢复时拒绝自动写入。恢复后只有在helper空闲、新鲜只读核验完整原排列一致时，才把会话归档到`CompletedLayouts`并释放下一次操作；不以UI缓存判断恢复。

重连只启用目标。如果系统已恢复原排列，不再写入。否则仅在身份集合、主屏及其他屏幕状态与原排列或授权临时排列一致时恢复完整原位置；目标旋转/原模式按需恢复。每次写入前重新核对当前状态，最终读取完整排列。出现新屏、人工移动、主屏改变或未知重排时停止布局写入。失败恢复仍可只启用目标，明确报告布局未恢复，不关闭新屏，不搬应用窗口。

## 确认与验收

独立原生面板从准备/执行阶段显示进度，进入确认后显示45秒倒计时；每个阶段只主动显示一次，不随计时反复抢焦点。取消、截止、身份检查、单次许可和原稳定采样硬期限保留。

新增14项纯函数回归：中间/边缘/竖屏/纵向/折线/不支持几何、主屏/内置/镜像/重叠/角点、计划篡改/跨开机、完整恢复、并发移动/新屏/旋转/身份、绝对漂移、写入前状态变化和枚举顺序。新增5项真实helper进程的模拟回归覆盖超时、取消、保留后重连、并发变化及计划篡改。所有测试均无真实显示器写入。

**0.4.9的新临时策略和完整重连路径尚未真机验收。** 旧版U2777B一次成功及Redmi两次失败保留在[验收记录](VALIDATION.md)，不能外推为新版通过。原生模拟面板已观察到可见且成功恢复模拟四屏；这不是硬件重排时的窗口可见性保证。
