# 旋转屏幕 · 1.0

点屏幕卡片，在“屏幕方向”选择0°、90°、180°或270°，点“预览旋转…”。预览列出目标、角度和需要移动的屏幕；最终确认只由现场用户执行。方向功能不连接或断开屏幕。

只改变目标方向。主屏仍在原点，其他屏幕方向、相对顺序不变；在保持原坐标可行时不移动，否则仅支持能安全靠拢的连续横排/竖排。复杂排列、镜像或身份不明确时拒绝。显示器的旋转模式尺寸由实际读回严格核验，系统自行作出未计划的移动不会直接覆盖。

执行前保存完整入口。独立helper串行持锁并握手，执行后需要新鲜、稳定的完整拓扑读回；系统返回成功不是完成。最后提交后的核验超时只允许一次有界只读双样本收尾，不重发写入。验证通过后45秒内点“保留方向”，否则尝试恢复入口。取消、关闭管理窗、睡眠或热插拔走同一保护；未知并发修改时拒绝覆盖，必要时只尝试启用恢复。

保留后原子更新独立办公室基线，原基线另存事务。完整办公室旋转保存完整新排列；远程单屏旋转只更新同次开机完整基线中的目标方向，并重新规划完整排列。基线被其他操作修改时不覆盖，保留已经确认的方向并显示失败原因。旧基线不会随后自动撤销已确认的方向。

## 最小现场测试

1. 保持另一块实体屏可见，准备系统显示器设置、目标屏菜单和单独视频线恢复；悠悠可能短断。
2. 选非主屏，先做一次0°→90°预览，核对目标和位置变化，由用户点击最终确认。
3. 检查画面、主屏和邻屏。第一次可点“立即恢复”，验证回到原方向；正常后再另起一次并点“保留方向”。
4. 若异常或恢复失败，停止重复，现场恢复并保留诊断。不要拔保留屏或整个扩展坞。

当前只有能力读取、单测、纯模拟和界面检查；没有agent执行真实旋转。不能把模拟或私有符号可加载写成真机通过。
