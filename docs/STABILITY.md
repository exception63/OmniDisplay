# 0.4.8：稳定采样的期限与证据

本次只修复断开后稳定采样的通用边界；不修改 DDC、单次许可、保留屏、旋转接口或写入前 CAS。Redmi 27 NU 的失败已由日志和离线回放定位，**0.4.8后续实测已通过初始稳定交接，但在最终位置核验失败；该屏持续断开仍未通过**。

## 状态与不变量

| 状态 | 可接受证据 | 转移 |
|---|---|---|
| 采样 | 完整且身份有效的拓扑；同一进程回调代数内，连续两次一致、均在截止前完成 | 原布局一致可完成；稳定但已重排继续等待宽限 |
| 持有重排证据 | 距截止不超过一个采样间隔，且最新有效观察到截止的年龄小于150毫秒 | 不再启动额外读取；以最多30毫秒的小步处理回调及取消，等宽限结束 |
| 宽限结束 | 至少两次一致观察；证据年龄不超过150毫秒；无新回调、pending重配、取消或保留屏失效 | 返回规划证据；后端每次写入前仍做新的只读拓扑比较（CAS） |
| 失效/失败 | 读取失败、冲突、回调变化、身份问题、晚读、陈旧证据 | 清除不再成立的配对，或拒绝并进入保护恢复；不借用旧证据绕过失败 |

宽限期和读截止仍是同一个 **1.2秒** 窗口。150毫秒是既有采样间隔，也是交接时证据的最大年龄；年龄按子进程实际采样完成时间计算，不以父进程收到结果的时间刷新。读取完成时已超过该年龄或时间戳早于本次读取/晚于接收时刻，也会拒绝；没有扩大初始稳定预算。真实 I/O 的独立进程上限不变。一次读取若已经在途并越过截止，即使之前有一致样本也明确失败，不接受晚读作为新票或退回旧票；审计保留原累计数以免误报。

回调代数只在同一监视器生命周期内比较，不比较不同观察进程的数字。读取期间有回调则该次结果失效；两次读取之间有回调则重新收集配对；持有证据等待期间有回调则直接拒绝。回调本身不读写显示设置。最终核验仍要求原布局，不能用“稳定但错误的布局”通过。
